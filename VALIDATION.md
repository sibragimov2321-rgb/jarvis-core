# Проверка реализации

Проверено локально 13 сентября 2026, Windows, Python 3.13.14.

- `pytest -q`: **29 passed**. Мок-транспорт без реальных записей в Google/Jules.
- Тесты покрывают маршруты и русский пример напоминания, границу года, неверное время,
  аутентификацию, точность preview письма, отмену/срок/одноразовость подтверждения,
  idempotency и неизвестный результат записи.
- Провайдерные тесты: PKCE/state/cookie, refresh token, сокрытие секретов в ошибках,
  payload Calendar/Tasks/Gmail/Jules, revision control Google Docs, конфликт/гонка, вкладки и история.
- Ruff: исходники, тесты, служебные скрипты без ошибок.
- `pip check`: зависимости совместимы.
- Python wheel собран.
- Реальный процесс Uvicorn: /health=200, /status без ключа=401, с ключом=200,
  /docs=200, OpenAPI содержит 16 путей. Процесс после проверки остановлен.
- Два deprecation warning из Starlette TestClient/httpx/AnyIO не влияют на результат тестов;
  миграцию тестового клиента нужно учесть при следующем обновлении зависимостей.

Не проверено: реальный OAuth consent/refresh с аккаунтом владельца, live Google/Jules/Gemini вызовы,
доставка push на iPhone, сборка/запуск Docker и реальный деплой Railway/VPS.
Для них нужны credentials, согласие Google и выбранный хостинг. Docker на машине не установлен.
Конфигурации контейнеров подготовлены; это не заявление об уже работающем production-сервисе.

Перед включением 24/7: заполнить .env, пройти OAuth, проверить чтение /memory,
создать собственное тестовое напоминание, проверить уведомление на iPhone, проверить backup/restore,
затем явно подтвердить deployment. Письма и удаления тестировать только на выбранных владельцем данных.
